# Editorial PDF: production rules

These rules apply to the selected task and supplied brief. Use judgment for reversible choices; preserve explicit user requirements.

## 1. Treat source text, tables, charts and page appearance as distinct evidence

Treat source text, tables, charts and page appearance as distinct evidence. For an existing PDF, inspect pages as well as extraction. Scanned inputs need OCR and verification; extracted text is not a layout reconstruction.

## 2. Define a document hierarchy and page grid before decorating: body measure/leading, heading levels, captions, footnotes, tables, figures, running furniture and page numbers

Define a document hierarchy and page grid before decorating: body measure/leading, heading levels, captions, footnotes, tables, figures, running furniture and page numbers. Choose readable body typography before cover art.

## 3. Rewrite only within authorized scope

Rewrite only within authorized scope. Preserve factual claims, caveats, comparisons, units, names, links and citation meaning. A cleaner narrative must not change the evidence.

## 4. Use a publishing engine suited to the document: structured typesetting, HTML/CSS print layout, or programmatic document generation

Use a publishing engine suited to the document: structured typesetting, HTML/CSS print layout, or programmatic document generation. Select current supported tools rather than pretending browser-only effects survive every PDF exporter.

## 5. Make figures serve the argument

Make figures serve the argument. Preserve original quantitative data and readable labels. Decorative imagery should not displace the evidence or make body pages inconsistent.

## 6. Design tables for the available width, repeated headers, meaningful alignment, units and long entries

Design tables for the available width, repeated headers, meaningful alignment, units and long entries. Do not hide required rows or shrink the table until it is technically inside the page but unusable.

## 7. Control pagination: orphan headings, widows, page breaks, split captions, empty end pages, footnote collisions, inconsistent page numbers and reference links

Control pagination: orphan headings, widows, page breaks, split captions, empty end pages, footnote collisions, inconsistent page numbers and reference links. Inspect every page, not only the cover.

## 8. Render the final PDF after substantive changes and review its actual page images

Render the final PDF after substantive changes and review its actual page images. Mechanical checks for page count/extractable text complement visual review. Fix source layout and regenerate rather than editing screenshots of pages.

## 9. For accessible delivery, use tagged/semantic source and inspect reading order/text equivalents through an appropriate checker

For accessible delivery, use tagged/semantic source and inspect reading order/text equivalents through an appropriate checker. A beautiful image-only PDF is not automatically accessible; supply the requested alternative.

## 10. For print, confirm dimensions, margins/bleed, fonts, raster placement, color/export settings and proof requirements

For print, confirm dimensions, margins/bleed, fonts, raster placement, color/export settings and proof requirements. Deliver PDF plus usable authoring source where needed, with any exporter limitations stated.
