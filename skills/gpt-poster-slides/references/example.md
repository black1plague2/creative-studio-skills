# Worked example: GPT poster slides

This is an original fictional exercise, not a claim of a real deployed product or evidence that every host can execute it.

## Request/input

A fictional CampusCart PRD asks for three 16:9 posters: concept, problem, and borrowing flow.

## Resolved brief

Students and judges; English; rich campus illustration; forest-green, cream, marigold and blue; no invented adoption metrics.

## Decisions and expected production

Generate a cover with the exact name/tagline; a problem image showing unused items and unmet need; and a left-to-right Find/Borrow/Return infographic with the same camera and characters. Save prompts and verify copy. Use the manifest to package three full-frame slide images. The repository's CampusCart example shows this process.

## Questions to avoid

Do not ask again for the stated audience, language, direction or output. Do not ask the user to choose minor spacing or filenames. Ask about a material missing fact/capability if it changes completion.

## What would fail

Invented product evidence, generic interchangeable treatment, an unrun check described as passed, or a production plan presented as a completed artifact. Apply the task-specific acceptance checks, not just this summary.
