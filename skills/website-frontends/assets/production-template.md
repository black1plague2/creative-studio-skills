## Filled example — ClayNest concept storefront

Domain: [commerce](../../../domains/commerce.md). Original fictional product illustrations; no active checkout, price, stock or delivery terms. Site purpose: explore three ceramic forms, with no purchase promise.

Hero: “Everyday forms. Quiet character.” CTA: “View the concept collection.” Collection section names cream mug, cobalt bud vase and terracotta bowl; each image caption states “Fictional product illustration.” CTA links to the real section; object buttons open readable detail panels with only the supplied visual descriptions. No review stars, scarcity badge or invented food-safety label.

Direction: warm editorial surface, considered object photography-style illustration and asymmetrical composition on wide screens; one-column sequence on narrow screens. Required checks: keyboard opens/closes detail panel and returns focus, objects stay uncropped, text survives long names/zoom, image failure leaves name/status visible. Implementation choice follows the existing project rather than imposing a new framework.

## Actual verification and delivery

Run the main journey in a browser, inspect wide/narrow screenshots and meaningful form/navigation states. Check keyboard focus, semantics, loading behavior, long content and reduced motion. Automated accessibility checks supplement manual review; they are not certification. Record viewport/browser and observed evidence. Deployment/publication requires authorization independent of code completion.
