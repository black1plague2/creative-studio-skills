# Creative copy: production rules

These rules apply to the selected task and supplied brief. Use judgment for reversible choices; preserve explicit user requirements.

## 1. Read the source before polishing

Read the source before polishing. Separate facts, proposed features, illustrative examples and opinions. Strengthening wording must not strengthen the underlying claim.

## 2. Write the subject and action directly

Write the subject and action directly. Prefer familiar verbs and concrete nouns to empty abstractions. Remove a phrase when it repeats the heading or adds no useful meaning.

## 3. Match the medium

Match the medium. A slide label must scan; narration must sound spoken; a document paragraph must connect reasoning; UI text must help the user act/recover; campaign text must explain the real offer.

## 4. Use a title form that fits the page

Use a title form that fits the page. A factual takeaway is useful when evidence supports it; a plain topic label can be clearer for setup or a mechanism. Do not force every title into a slogan or sentence claim.

## 5. Keep the source's caveats, units, comparison and implementation status

Keep the source's caveats, units, comparison and implementation status. Never manufacture certainty, testimonials, statistics, dates or promises to make the copy sound polished.

## 6. Build connected sentences with varied length and useful transitions

Build connected sentences with varied length and useful transitions. Avoid repeated opening patterns, excessive labels, decorative punctuation and uniform short slogans when they flatten the reasoning.

## 7. For narration, read aloud or audition

For narration, read aloud or audition. Replace tongue-twisting clauses and clarify acronym/number pronunciation. Do not add filler words merely to simulate being human.

## 8. For UI, use specific action labels and recovery-oriented errors

For UI, use specific action labels and recovery-oriented errors. Describe what will happen, not internal architecture. Keep instructions near the action and avoid blaming the user.

## 9. For generated image text, prepare an exact-copy list and shorten it faithfully before generation

For generated image text, prepare an exact-copy list and shorten it faithfully before generation. Preserve a separate text version for verification and accessibility.

## 10. Review with the source side by side, then check in the actual layout/audio context

Review with the source side by side, then check in the actual layout/audio context. Deliver the requested copy and variants with meaningful rationale, not an arbitrary list of equally weighted alternatives.
