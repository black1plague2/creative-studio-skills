# Data storytelling: useful questions

Read first; the source may already answer these. Ask only what materially changes the message, form, operation or delivery. Normally ask at most three questions in one batch.

- Which source data and comparison/question should the visual answer?
- What audience, medium, time range, units and aggregation are intended?
- Which uncertainty, missing-data, confidentiality and exact-output constraints matter?

## Decision policy

- Already specified: retain the answer; do not ask again.
- Reversible choice: choose a sensible option, state it, and proceed.
- Missing factual content: ask or clearly leave the claim unresolved; do not fabricate.
- Tool-dependent deliverable: check the capability before promising the artifact.
- Ambiguous expensive direction: show a representative real-content sample when possible.
- User says to decide: choose a coherent direction rather than presenting endless options.

Use concise choices with the practical difference when they help. Do not make the user choose every font, spacing value, crop or implementation detail. Questions are a means to improve production, not a substitute for completing authorized work.
