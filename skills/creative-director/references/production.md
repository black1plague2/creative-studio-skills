# Creative director: production rules

These rules apply to the selected task and supplied brief. Use judgment for reversible choices; preserve explicit user requirements.

## 1. Map input type to its evidence

Map input type to its evidence. A PRD supplies requirements and hypotheses; an existing deck may supply narrative and visual references; a PDF may contain both text and visual evidence; notes may contain unresolved decisions. Keep these roles distinct.

## 2. Build a compact source ledger: claim or content item, source location, supplied/verified/illustrative status, caveat, and intended artifact

Build a compact source ledger: claim or content item, source location, supplied/verified/illustrative status, caveat, and intended artifact. Preserve user-provided uncertainty. Do not promote a roadmap feature into an implemented capability.

## 3. Extract the audience, job, key message, must-keep material, visual references, output formats, and actual tool capabilities before asking

Extract the audience, job, key message, must-keep material, visual references, output formats, and actual tool capabilities before asking. Identify contradictions that would change the artifact rather than asking for every missing preference.

## 4. For a bundle, choose one shared identity and a different information treatment per medium

For a bundle, choose one shared identity and a different information treatment per medium. A dense PDF page cannot become a good video scene merely by moving its heading. A marketing hero is not automatically an app navigation system.

## 5. Choose the smallest useful bundle

Choose the smallest useful bundle. A request for a deck does not authorize a website, campaign, narrated film, or publication. Suggest an additional artifact only when it solves a real communication need.

## 6. Plan a representative sample where direction is expensive: cover plus technical poster, primary UI flow with an error state, two-page document spread, or short narrated scene

Plan a representative sample where direction is expensive: cover plus technical poster, primary UI flow with an error state, two-page document spread, or short narrated scene. Skip unnecessary approval interruption when the user has already specified the direction.

## 7. Route slides to GPT poster slides; route source charts to data storytelling; route video narration to natural voiceover; route text to creative copy only when substantive rewriting is part of the task

Route slides to GPT poster slides; route source charts to data storytelling; route video narration to natural voiceover; route text to creative copy only when substantive rewriting is part of the task. Keep one owner for final art direction.

## 8. Represent dependencies honestly

Represent dependencies honestly. A video cannot reach delivery without usable audio if narration was requested. A GPT poster cannot reach generation without GPT image tools. Produce independent source/planning work and a concrete handoff when a capability is missing.

## 9. Track the production state with a small checklist: source ready, brief ready, representative sample, build, source check, visual/interaction/audio check, final export

Track the production state with a small checklist: source ready, brief ready, representative sample, build, source check, visual/interaction/audio check, final export. Mark blocked or unrun steps as such; do not call a plan a finished creative.

## 10. At delivery, preserve the requested outputs and provide meaningful project sources

At delivery, preserve the requested outputs and provide meaningful project sources. Explain material limitations and what was checked. Keep publishing separate from artifact creation unless explicitly authorized.
