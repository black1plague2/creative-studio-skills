# Worked example: Creative director

This is an original fictional exercise, not a claim of a real deployed product or evidence that every host can execute it.

## Request/input

A PRD describes CampusCart, a fictional campus item-borrowing concept. The user asks for a three-slide pitch and a short product explainer.

## Resolved brief

Audience: student hackathon judges. Goal: explain the idea and primary borrowing flow. Poster direction: illustrated campus world. Video: English, roughly one minute, 16:9, narration required. The PRD supplies no adoption data.

## Decisions and expected production

Create a source ledger and a three-slide plan: concept, unused-item problem, find/borrow/return. Route posters to GPT. Write a separate demonstration-based video script with a voice audition step. Mark every UI screen as a concept illustration. Do not invent downloads, revenue, testimonials, or an implementation claim.

## Questions to avoid

Do not ask again for the stated audience, language, direction or output. Do not ask the user to choose minor spacing or filenames. Ask about a material missing fact/capability if it changes completion.

## What would fail

Invented product evidence, generic interchangeable treatment, an unrun check described as passed, or a production plan presented as a completed artifact. Apply the task-specific acceptance checks, not just this summary.
