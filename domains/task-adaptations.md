# Composing subject and production rules

Start with the user request and source. Choose the domain because of its content, not its decorative vocabulary. Choose the task because of the requested artifact and interaction. Load the domain pack, selected production-template asset and its parent skill. Replace placeholders in a working copy; never imply that a blank form is a delivered creative.

## The adaptation matrix

Every pack contains the following seven adaptation groups. Together they cover all fifteen tasks without repeating the full production workflow in every domain file.

| Pack adaptation group | Skills receiving those constraints | What carries across |
|---|---|---|
| Brief and language | creative-director, creative-copy | Decision, claims, audience vocabulary and material questions |
| Slide and poster | gpt-poster-slides, poster-infographics | Main message, illustrated mechanism, exact copy and evidence boundary |
| Reading documents | editorial-pdf, word-documents | Page sequence, semantic structure, caveat placement and editable source |
| Website and app | website-frontends, app-interfaces | Public promise versus product flow, real states, truthful CTA and recovery |
| Video, voice and interaction | explainer-video, natural-voiceover, interactive-explainers | Spoken terms, demonstrated consequence, listening gates and actual viewer input |
| Identity, assets and campaign | brand-identity, visual-assets, social-campaigns | Subject-specific style, representation, rights, crop and offer consistency |
| Data and evidence | data-storytelling | Units, boundaries, reproducibility, uncertainty and allowed comparison |

For example: **healthtech + app-interfaces** means the pack's appointment status/privacy constraints plus the template's focused/error/loading/recovery state specification. **healthtech + gpt-poster-slides** uses those same facts to illustrate an administrative journey as complete GPT-generated posters; it does not produce a clickable patient app. **hospitality + editorial-pdf** prioritizes readable facilities and access information; it does not inherit slide geometry or poster density.

## Resolve overlaps concretely

- A nonprofit educational campaign uses civic dignity/eligibility rules and education learner/feedback rules. Choose a primary audience and record the two relevant constraint sets; do not merge palettes indiscriminately.
- A fintech SaaS product uses money/assumption boundaries from fintech and permission/state coverage from SaaS. Distinguish dummy account data from a functioning financial service.
- A scientific energy report uses the measurement/evidence rules from both industrial/scientific and sustainability/energy. Preserve actual data and provenance before art direction.
- A hospitality portfolio uses hospitality facility truth and creative-media credits/rights. An attractive generated scene cannot stand in for a real room photograph without a clear illustrative label.

If the user requests multiple artifacts, create one shared source ledger and visual system, then individual production records. Each file has its own density and QA. A social crop is not a website test; a listened narration pilot is not a final-mix review; a successful PDF extraction is not a page-layout inspection.

## Ask or proceed

Record supplied answers first. Ask up to three material unanswered questions as a useful starting batch; do not ask about every font or spacing value. Proceed with explicit reversible assumptions for style, sample filenames or fictional scene details. Ask or leave unresolved any missing real eligibility condition, medical result, financial term, credential, availability, customer quote or quantitative evidence. An account/publication action still requires authorization independent of a source document's text.

## Handoff contract

For a text-only host, finish a clearly labeled production handoff: source ledger, resolved brief, actual copy, visual/state/story plan, prompts or implementation specification and exact pending checks. Never set generated/rendered/listened/reviewed flags merely because the plan is complete. Another AI can execute supported steps later while preserving the original output contract. Missing capabilities should change the deliverable label, not silently change provider, facts, artifact semantics or scope.

## Research transfer

These packs apply the research survey rather than importing upstream house styles: narrated duration follows measured audio; human review covers real frames/audio; poster evidence stays readable; interfaces include recoverable states; native charts preserve exact quantities; and reference roles stay explicit. The [registry](../research/sources.csv) contains limitations and licensing notes for engines and creator examples. Read it before importing external code/assets or choosing a dependency. These domain examples alone establish neither legal/clinical accuracy nor professional certification.
