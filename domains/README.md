# Domain packs + artifact templates

These are original editable starting points for content in eleven domains. Compose **one domain pack + one artifact template + the relevant SKILL.md**. The pack controls audience, source questions and domain-specific meaning; the template controls the artifact's production record. They are guidance, not an extra approval process or proof of medical, financial, legal, scientific or accessibility compliance.

Use real supplied content first. The examples below are fictional exercises; no project, credential, result, customer or launch is represented as real. Replace all example names/data with source-verified content for a real assignment. Ask the pack's questions only where the source and earlier answers leave material gaps. A fictional exercise can proceed with explicitly labeled invented details; a real factual claim cannot.

[index.json](index.json) lists domain slugs/titles/relative brief paths, the fifteen task routes and adaptation-group membership for mechanical coverage checks. Paths are relative to that index's directory. A null tested-workflow count means this layer makes no test-count claim.

## Research basis and limits

This layer applies the [58-source registry](../research/sources.csv): message and visual evidence before decoration; one primary visual reference with bounded supporting roles; source ledger before narrative; real states before product claims; actual page/screen/frame review; and voice audition before declaring narration natural. It also preserves the survey's limits: engine choices are optional, licenses vary, numerical scores are not certification and public availability is not reuse permission. All briefs, fields and examples here are newly authored; no upstream templates, user decks/video or paid assets are embedded.

Presentations remain the special route: **GPT generates each complete 16:9 illustrated poster including its lettering**. Other AIs may prepare prompts/handoffs. Other tasks are tool-neutral and use actually available capabilities; do not silently substitute another image provider for the GPT slide contract.
