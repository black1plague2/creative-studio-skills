# Copyable task prompts

Replace the content fields with real information; do not treat blanks as permission to invent facts.

## GPT: poster slides from a PRD

```text
Read this repo's START_HERE.md and skills/gpt-poster-slides/SKILL.md,
including the GPT workflow, art-direction and quality/export references.
Use my attached PRD as the source. Audience: student hackathon judges.
Make 8 slides total, English, 16:9. Generate complete illustrated poster
images with GPT image generation. Use a coherent topic-specific identity.
Include a designed architecture plate and user-flow infographic when
supported by the PRD. Preserve proposal/implemented status and exact facts.
Ask only material gaps not answered here. Deliver images, PDF and an
image-based PPTX when tools permit. Inspect the actual output.
```

## Any AI: turn a presentation into a short explainer

```text
Use creative-director, explainer-video and natural-voiceover from this repo.
Read the attached presentation and inspect its visual references.
Audience: prospective users. Target: roughly 60–90 seconds, 16:9.
Use illustrated demonstrations, readable captions and conversational
narration. Ask which language/accent or narrator route I want if unknown.
Do not simply pan over slides. Time visuals from measured speech.
Deliver the video, caption/transcript and editable project source.
If direct listening is unavailable, mark voice naturalness unreviewed.
```

## Any AI: app UI from requirements

```text
Use app-interfaces from this repo. Inspect the attached requirements and
existing project first. Build the primary task flow in the existing stack.
First show three concrete UI examples/directions with my actual task
content so I can choose. Preserve any direction I already accepted.
Preserve the established brand and component system. Cover loading, empty,
error, success, keyboard/focus and narrow layouts where relevant.
Ask only missing facts that change the operation or product requirements.
Implement actual controls and explain any conceptual/backend limitation.
Inspect the rendered UI and exercise the main journey before delivery.
```

## Any AI: reading-first PDF

```text
Use editorial-pdf and creative-copy from this repo. Turn these notes and
figures into a concise report for the stated audience. Preserve exact
source data and meaningful caveats. Choose an appropriate page hierarchy,
body typography, tables and figure treatment. Ask about print/page size
only if it changes the requested delivery. Render and inspect every page.
Deliver PDF plus usable authoring source when available.
```

## Any AI: several creatives from an incomplete idea

```text
Use creative-director from this repo. First extract what my idea already
establishes. Ask a small batch of relevant questions about audience,
purpose, actual content and requested deliverables. Choose sensible
reversible details for me. Route the resolved task to the relevant skill,
build the artifact with available tools, inspect it, and deliver honestly.
Do not make the questionnaire the final outcome.
```
